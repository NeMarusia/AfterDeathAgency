# Агентство постсмертного сопровождения

Сатирическая idle-игра о работе потусторонней канцелярии. Игрок рассматривает дела прибывших душ, выбирает маршрут, развивает отделы агентства и переживает проверки Министерства посмертных дел.

## Версия 0.2

- полноценный цикл рассмотрения дел;
- пять развиваемых отделов;
- пассивный и офлайн-доход;
- случайные события без разрушительного обнуления прогресса;
- достижения, серии верных решений и рабочие дни;
- адаптивный интерфейс для desktop и Android;
- автоматическая web- и APK-сборка через GitHub Actions.

## Запуск

Требуется Godot 4.4.1 или новее. Откройте `project.godot` и запустите сцену `main.tscn`.

## Автоматические сборки

Workflow `.github/workflows/build.yml`:

1. экспортирует web-версию;
2. публикует её через GitHub Pages;
3. собирает отладочный APK;
4. прикладывает APK как GitHub Actions artifact.

## Монетизация

Кнопка временного ускорения уже выделена как точка rewarded-рекламы. Для боевого релиза требуется подключить рекламный SDK и подставить App ID магазина. Тестовая версия выдаёт награду напрямую и не собирает пользовательские данные.
