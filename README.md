# Агентство пост-смертного сопровождения

**«Агентство пост-смертного сопровождения»** — это ироничный кликер с элементами менеджмента и бюрократического абсурда. Игрок берёт на себя роль сотрудника потусторонней канцелярии: отпускает души, нанимает духоводов и справляется с хаосом сверхъестественной бюрократии.

---

## Особенности

- Кликерная механика: отпускай души и развивай агентство.
- Автоматизация: нанимай духоводов для пассивного прироста.
- Система случайных событий (эвентов), влияющих на процесс.
- Оформление в стиле пиксель-арт и ручная озвучка действий.
- Элементы юмора и атмосфера ада из "Благих знамений".

---

## Установка и запуск

1. Установите Godot Engine версии 4.4.1 или выше.
2. Клонируйте репозиторий:

   ```
   git clone https://github.com/NeMarusia/AfterDeathAgency.git
   cd AfterDeathAgency
   ```

3. Откройте проект в Godot.
4. Запустите сцену `Main.tscn`.
