# Агентство пост-смертного сопровождения

**«Агентство пост-смертного сопровождения»** — ироничный кликер с элементами менеджмента и бюрократического абсурда. Игрок берёт на себя роль сотрудника потусторонней канцелярии: отпускает души, нанимает духоводов и справляется с хаосом сверхъестественной бюрократии.

## Особенности

- Кликерная механика: отпускай души и развивай агентство.
- Автоматизация: нанимай духоводов для пассивного прироста.
- Система случайных событий, влияющих на процесс.
- Оригинальное пиксельное оформление.
- Летающие души с несколькими эмоциональными состояниями.
- Авторские звуки и атмосферная музыка.
- Элементы юмора и атмосфера ада из «Благих знамений».

## Запуск

Требуется Godot Engine 4.4.1 или новее.

```bash
git clone https://github.com/NeMarusia/AfterDeathAgency.git
cd AfterDeathAgency
```

Откройте `project.godot` и запустите сцену `main.tscn`.
